# Music App (iOS)

An iOS app for ear training and music exploration, including melody playback,
interval practice, and chord-based exercises.

This project was built as a personal learning tool and evolved over time as
new musical ideas and features were added.

## Features
- Melody playback using SoundFont instruments
- Single interval identification exercises
- Atonal interval identification exercises (3-4 notes)
- Diatonic interval identification exercises (3-4 notes)
- Single chord identification exercises 
- Diatonic multiple chord identification exercises (3-4 chords)
- Voice exercises
- Whistling exercises
- Ocarina exercises

## Tech
- Swift
- SwiftUI
- AVFoundation / MIDI
- Xcode

## Status
Personal project. Actively experimented with; not intended as a polished
commercial release.
